##  Investigación complementaria

### NIST Cybersecurity Framework 2.0

NIST CSF 2.0 ofrece una estructura para que organizaciones de diferentes tamaños y sectores puedan entender, evaluar, priorizar y comunicar sus riesgos de ciberseguridad. Para ISD Colombia resulta útil como referencia de gestión porque el análisis STRIDE identifica riesgos concretos mientras que el CSF permite contextualizarlos dentro de una estrategia de gestión del riesgo y mejora continua.

### OWASP ASVS

OWASP ASVS establece una base para verificar controles técnicos de seguridad de aplicaciones y para transformar principios de seguridad en requisitos comprobables. Para la solución futura de ISD Colombia, esta referencia es útil para complementar los requisitos de autenticación, control de acceso, protección de datos y manejo seguro de entradas.

### OWASP API Security Top 10

Si la solución futura de ISD Colombia incorpora una API para comunicación entre frontend, backend, automatización, servicios externos o módulos de inteligencia, los riesgos específicos de APIs deben considerarse desde el diseño. Por ello, el OWASP API Security Top 10 se deja como referencia complementaria para las siguientes fases.

### OWASP Juice Shop

Juice Shop es una aplicación deliberadamente vulnerable desarrollada para formación en seguridad. En el taller se utiliza como entorno seguro para ejecutar retos controlados y relacionar evidencia práctica con categorías STRIDE. En la presente entrega la práctica queda marcada como pendiente de evidencia de ejecución del equipo.
