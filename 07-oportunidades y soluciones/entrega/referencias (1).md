## Patrones de arquitectura, seguridad y cumplimiento

3. **NIST Cybersecurity Framework (CSF) 2.0.** National Institute of Standards and Technology. Utilizado como referencia para estructurar la gestión y priorización de riesgos de ciberseguridad.  
   https://www.nist.gov/publications/nist-cybersecurity-framework-csf-20

4. **NIST SP 800-207 — Zero Trust Architecture.** Utilizado como referencia para el diseño de identidad, autenticación y autorización por recurso.  
   https://www.nist.gov/publications/zero-trust-architecture

5. **NIST SP 800-207A — A Zero Trust Architecture Model for Access Control in Cloud-Native Applications in Multi-Cloud Environments.** Referencia para considerar identidades de usuarios y servicios dentro de aplicaciones modernas.  
   https://csrc.nist.gov/pubs/sp/800/207/a/final

6. **OWASP Application Security Verification Standard (ASVS) 5.0.0.** Utilizado como base para convertir requisitos de seguridad de la aplicación web en controles verificables.  
   https://owasp.org/projects/asvs

7. **OWASP API Security Top 10.** Utilizado para orientar controles sobre integraciones y APIs con terceros.  
   https://api-security.owasp.org/

8. **Ley Estatutaria 1581 de 2012 — Superintendencia de Industria y Comercio.** Referencia normativa para protección de datos personales en Colombia. Su aplicación concreta al cliente debe consolidarse con el Taller 6.  
   https://sedeelectronica.sic.gov.co/transparencia/normativa/ley-estatutaria-1581-de-2012

9. **Decreto 1074 de 2015 — Función Pública.** Referencia del marco reglamentario del sector Comercio, Industria y Turismo. El alcance aplicable a ISD debe ser validado con el Taller 6.  
   https://www.funcionpublica.gov.co/eva/gestornormativo/norma.php?i=76608

## Criterio de uso de fuentes

Las fuentes NIST y OWASP se utilizan como patrones y referencias técnicas; no se presentan como evidencia de que ISD Colombia ya implemente esos controles. Las fuentes normativas colombianas se incluyen como base de validación y no como conclusión de incumplimiento.
